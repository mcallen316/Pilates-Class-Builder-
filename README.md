# Pilates Class Builder

A standalone browser-based Pilates class planner and rehearsal timer.

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then click **Save**.
6. GitHub will publish the site and show a **Visit site** link in the Pages settings.

## Saving classes

The app saves class edits in your browser using local storage. Those saved edits stay on that browser/device, not in GitHub. Use the app's Export Backup feature if you want a portable backup.

Pilates Class Builder — Auto Advance Version

Upload index.html to the root of your existing GitHub Pages repository, replacing the old index.html.
Your saved classes remain in browser localStorage as long as you keep the same GitHub Pages URL.

New Instructor View features:
- Automatically advances to the next exercise using each block's estimated duration.
- Large cumulative class clock.
- 'Minute X.X of 60' display.
- Countdown until the next block.
- Manual Skip/Next remains as a backup.
- A zero-duration block will NOT auto-advance; give it a time first.
